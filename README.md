# JusRadar Updates

Repositório público usado somente para distribuir atualizações oficiais do JusRadar para Windows.

Este repositório não contém o código-fonte do JusRadar.

Os arquivos publicados em Releases incluem:
- JusRadar-Setup.exe
- latest.json

O aplicativo JusRadar verifica o arquivo latest.json para saber quando existe uma nova versão disponível.
